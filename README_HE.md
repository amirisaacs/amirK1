2. צרו טופס עם השדות:

   - עבור מי האימון? (אני / ילד או ילדה / נער או נערה)

   - מתי נוח לחזור אליי? (בוקר / צהריים / ערב)

3. בהגדרות הטופס הפעילו התראות על הגשות חדשות.
4. חברו את הטופס ל-Google Sheets דרך Integrations, כדי שכל פנייה תתווסף לגיליון.

6. פתחו את `script.js` והחליפו:
   `const TALLY_FORM_ID = "YOUR_TALLY_FORM_ID";`
   במזהה האמיתי שלכם.
7. שמרו, העלו ל-GitHub ובדקו שליחת ליד אמיתי. ודאו שהפנייה מופיעה גם ב-Tally וגם ב-Google Sheets ומגיעה התראת מייל.

## 5. העלאה ל-GitHub Pages

1. היכנסו ל-GitHub וצרו Repository חדש, למשל `amir-k1-landing`.
2. העלו את כל הקבצים והתיקייה `assets` (כולל התמונות) לשורש ה-Repository.
3. פתחו Settings → Pages.
4. תחת Build and deployment בחרו `Deploy from a branch`.
5. בחרו Branch `main` ותיקייה `/ (root)` ואז Save.
6. לאחר סיום הפריסה, GitHub יציג כתובת אתר. בדקו אותה גם בטלפון.
